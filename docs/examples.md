## 示例1：咨询类问题

### 用户查询

```
什么是学术不端行为？
```

### 处理流程

1. **复杂度判断**：`simple`
2. **意图识别**：`咨询类`
3. **术语预处理**：提取关键词 "学术不端行为"
4. **查询优化**：生成检索策略（top_k=10, min_score=0.4, max_rounds=1）
5. **循环检索**：1轮检索，获取相关定义和规范
6. **响应生成**：生成自然对话风格的答案

### 响应示例

```
学术不端行为是指在学术活动中违反学术规范和道德准则的行为。根据教育部《高等学校预防与处理学术不端行为办法》，主要包括以下几种类型：

1. 剽窃、抄袭他人成果
2. 伪造、篡改数据或文献
3. 伪造科研事实
4. 未参与研究，在成果上署名
5. 未经授权使用他人成果
6. 一稿多投
7. 其他违反学术规范的行为

（来源：教育部《高等学校预防与处理学术不端行为办法》）
```

## 示例2：行为判断类问题

### 用户查询

```
我能否在论文中重复使用自己已发表的内容？
```

### 处理流程

1. **复杂度判断**：`standard`
2. **意图识别**：`行为判断类`
3. **术语预处理**：提取关键词 "重复使用", "已发表内容", "自我抄袭"
4. **行为要素提取**：
   - 行为类型：重复使用
   - 对象：自己已发表的内容
   - 条件：论文中
5. **知识库检索**：检索相关规范和案例（15-25个片段）
6. **上下文扩展**：扩展为3-10个完整段落
7. **重排序**：基于相关性、权威性、完整性排序
8. **置信度评估**：评估判断结果的置信度
9. **响应生成**：生成判断结果和建议

### 响应示例

```
在论文中重复使用自己已发表的内容需要谨慎处理，因为这可能涉及自我抄袭问题。

根据学术规范，以下情况可以合理使用：

✅ 允许的情况：
- 明确标注为引用自己已发表的内容
- 使用引号或特殊格式标注
- 在参考文献中列出原文
- 说明重复使用的必要性

❌ 不允许的情况：
- 未做任何标注直接复制粘贴
- 声称为全新内容
- 大量复制超过合理引用范围（通常不超过10-20%）
- 在不知情的情况下，两个期刊同时发表相同内容

建议：如果您需要使用自己已发表的内容，请明确标注来源，并确保符合期刊或会议的具体要求。部分期刊允许作者在合理范围内引用自己的作品，但必须遵守引用规范。

（来源：各高校学术规范、学术期刊投稿指南）

置信度：0.92（高）
```

}
```

  ]
}

## 示例3：混合类问题

### 用户查询

```
自我抄袭的定义是什么，我之前发表的内容可以引用吗？
```

### 处理流程

1. **复杂度判断**：`standard`
2. **意图识别**：`混合类`
3. **术语预处理**：提取关键词 "自我抄袭", "定义", "引用", "已发表内容"
4. **查询拆分**：
   - 咨询部分：自我抄袭的定义是什么
   - 判断部分：我之前发表的内容可以引用吗
5. **并行处理**：
   - 咨询部分：调用咨询类子图（2轮循环检索）
   - 判断部分：调用判断类子图（增强检索）
6. **结果整合**：将咨询和判断结果整合
7. **响应生成**：生成统一的答案

### 响应示例

```
关于您的问题，我来为您详细解答：

**什么是自我抄袭？**

自我抄袭（Self-plagiarism）是指作者在未适当标注或引用的情况下，重复使用自己已发表作品中的内容。虽然抄袭的对象是自己的作品，但违反了学术诚信和出版规范，因为：

1. 侵犯了读者的知情权
2. 可能构成重复发表
3. 损害学术资源的公平分配

**之前发表的内容可以引用吗？**

可以引用，但需要遵守以下规范：

✅ 正确做法：
- 明确标注为引用自己已发表的内容
- 使用引号或特殊格式标注引用部分
- 在参考文献中列出原文的完整引用信息
- 说明引用的必要性（如避免重复研究、保持连贯性等）
- 控制引用比例，一般不超过文章总字数的10-20%

❌ 避免的做法：
- 未做任何标注直接复制粘贴
- 将已发表的内容作为"全新内容"再次发表
- 在不知情的情况下，向不同期刊同时投稿相同内容
- 大量复制导致新文章缺乏原创性

具体要求可能因期刊或会议而异，建议您在投稿前仔细阅读目标期刊的作者指南。

（来源：国际学术出版伦理委员会（COPE）指南、各高校学术规范）
```

### 查询拆分

  "judge_query": "我之前发表的内容可以引用吗",

    "key_terms": ["自我抄袭", "引用", "已发表内容"],

}
```

## 示例4：复杂查询

### 用户查询

```
请详细说明自我抄袭的定义，以及在不同学术领域（如计算机科学、人文社科、自然科学）的具体表现形式和判定标准，同时分析自我抄袭与合理引用的界限，并提供相应的规范建议。
```

### 处理流程

1. **复杂度判断**：`complex`
2. **意图识别**：`咨询类`
3. **术语预处理**：提取关键词 "自我抄袭", "定义", "表现形式", "判定标准", "合理引用", "规范建议"
4. **查询优化**：生成检索策略（top_k=20, min_score=0.25, max_rounds=3）
5. **循环检索**：3轮检索，逐步提升质量
   - 第1轮：广泛检索（top_k=20, min_score=0.25）
   - 第2轮：精准检索（top_k=10, min_score=0.6）
   - 第3轮：深度检索（top_k=8, min_score=0.7）
6. **上下文提取**：提取关键概念、关系图谱、缺失方面
7. **改善分析**：评估下一轮的改善潜力
8. **响应生成**：生成详细的答案

### 响应示例

```
这是一个非常全面的问题，我将从多个维度为您详细解答：

**一、自我抄袭的定义**

自我抄袭（Self-plagiarism），又称文本回收（Text Recycling），是指作者在未适当标注或引用的情况下，重复使用自己已发表作品中的内容。根据COPE（国际学术出版伦理委员会）的定义，自我抄袭主要包括：

1. 重复发表（Duplicate Publication）：将同一篇论文或大部分内容投递给多个期刊
2. 切片发表（Salami Slicing）：将一项研究拆分成多篇小论文发表
3. 文本回收：在不标注的情况下，重复使用自己之前作品中的段落、图表、数据等

**二、不同学术领域的具体表现形式**

**计算机科学领域：**
- 重复使用之前论文中的算法描述
- 重复使用相同的实验设置和结果
- 在不同论文中重复引用相同的数据集，未标注来源

**人文社科领域：**
- 重复使用之前发表的论点和论证逻辑
- 重复使用相同的文献综述和引用
- 在不同文章中重复描述相同的理论框架

**自然科学领域：**
- 重复使用相同的实验方法和结果
- 重复发表相同的数据分析
- 在不同论文中重复使用相同的图表和表格

**三、判定标准**

1. **重复比例**：一般而言，如果重复内容超过文章总字数的10-20%，可能构成自我抄袭
2. **是否标注**：未标注的重复使用视为自我抄袭，已标注的合理引用则可接受
3. **出版目的**：如果重复使用是为了避免冗长说明、保持连贯性等合理目的，且已标注，通常可接受
4. **期刊规范**：不同期刊有不同的规定，需遵守目标期刊的作者指南

**四、自我抄袭与合理引用的界限**

**合理引用的特征：**
- 明确标注引用来源
- 使用引号或特殊格式
- 在参考文献中列出完整引用信息
- 引用内容相对较少，通常不超过段落
- 有明确的引用目的（如对比、延续研究等）

**自我抄袭的特征：**
- 未标注或模糊标注
- 引用内容篇幅较大
- 作为文章的主体内容
- 缺乏必要的引用目的说明

**五、规范建议**

1. **写作前**：查阅目标期刊的作者指南，了解对自我引用的规定
2. **写作中**：
   - 如需引用自己已发表的内容，务必明确标注
   - 使用引号或特殊格式标注引用部分
   - 在参考文献中列出完整的引用信息
   - 说明引用的必要性（如"为了避免重复描述..."）
3. **投稿前**：自查重复比例，确保符合期刊要求
4. **特殊情况下**：如果不确定，可以向期刊编辑部咨询或说明

（来源：COPE指南、各高校学术规范、学术期刊作者指南）
```

## 示例5：多轮对话

### 第一轮对话

**用户**：
```
什么是学术不端行为？
```

**助手**：
```
学术不端行为是指在学术活动中违反学术规范和道德准则的行为。主要包括：

1. 剽窃、抄袭他人成果
2. 伪造、篡改数据或文献
3. 伪造科研事实
4. 未参与研究，在成果上署名
5. 未经授权使用他人成果
6. 一稿多投
7. 其他违反学术规范的行为

（来源：教育部《高等学校预防与处理学术不端行为办法》）
```

### 第二轮对话

**用户**：
```
那剽窃和抄袭有什么区别？
```

**助手**：
```
剽窃和抄袭都是学术不端行为，但有一些细微的区别：

**剽窃（Plagiarism）**：
- 更强调"窃取"他人成果并据为己有
- 通常涉及将他人的思想、文字、数据、创意等据为己有
- 即使做了轻微修改，如果未标注来源，仍属于剽窃
- 严重程度较高，涉及欺骗和盗窃

**抄袭（Copying）**：
- 更强调"复制"他人的内容
- 通常指直接复制他人的文字、图表、数据等
- 可能未做任何修改或仅做轻微修改
- 严重程度相对较低，但仍属于学术不端

在实践中，这两个概念经常被混用，泛指未经授权或未标注来源地使用他人成果的行为。无论哪种形式，都违反了学术诚信原则。

（来源：学术规范指南、各高校学术道德教育材料）
```

### 第三轮对话

**用户**：
```
如果我在引用时做了改写，还需要标注来源吗？
```

**助手**：
```
是的，即使做了改写，仍然需要标注来源。

**原因：**

1. **思想的来源**：即使改变了表达方式，思想本身仍然来源于原作者
2. **学术诚信**：标注来源是对原作者的尊重，也是学术诚信的基本要求
3. **可验证性**：标注来源可以让读者追溯原始信息，验证准确性

**正确做法：**

✅ 改写后标注：
```
根据张三（2020）的研究，学术不端行为主要包括剽窃、抄袭、伪造数据等类型。
```

✅ 在参考文献中列出：
```
张三. (2020). 学术不端行为的类型与防范. 《学术研究》, 3(2), 45-52.
```

❌ 错误做法：
```
学术不端行为主要包括剽窃、抄袭、伪造数据等类型。（未标注来源）
```

**例外情况：**

只有当以下条件同时满足时，才可能无需标注：
- 内容属于常识或公理（如"地球是圆的"）
- 该内容在多个独立来源中都有相同的表述
- 无特定的作者可追溯

但学术领域的专业内容通常不属于例外情况，建议谨慎处理。

（来源：APA引用规范、各高校学术规范）
```

## 总结

通过以上示例，可以看出学术诚信助手工作流具有以下特点：

1. **意图识别**：能够准确识别咨询类、行为判断类、混合类问题
2. **复杂度感知**：根据问题复杂度动态调整检索策略
3. **循环优化**：通过多轮检索和 LLM 增强持续提升质量
4. **结构化响应**：生成清晰、专业、可信的答案
5. **标注来源**：每个观点标注信息来源，提供可验证性
6. **对话友好**：支持多轮对话，能够处理追问和模糊问题
