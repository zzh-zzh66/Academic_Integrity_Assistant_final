# 学术道德规范模拟问题（20题）
本套题目覆盖大学生、研究生、科研人员、大学老师等不同群体，涉及学术研究、论文撰写、成果发表、教学指导等多个场景。

## 一、 通用基础类（适用于所有群体）
1.  什么是学术不端行为？请列举至少5种常见的学术不端表现形式。
2.  学术道德规范的核心原则有哪些？这些原则在学术研究的全流程中起到什么作用？
3.  简述学术诚信与个人学术生涯发展的关系，结合实例说明违背学术诚信的长期危害。
4.  当你在学术活动中发现他人存在学术不端行为时，正确的处理流程是什么？需要注意哪些事项？
5.  学术规范中的“署名规则”包含哪些要求？如何判定学术成果的署名资格？

## 二、 大学生专属类
6.  大学生在课程论文撰写中，如何正确引用网络上的公开资料？直接复制粘贴网络内容但标注出处，是否属于抄袭？
7.  小组课程设计或实验报告中，部分成员“搭便车”未参与实质工作却要求署名，作为团队负责人应该如何处理？
8.  期末考试或课程考核中，哪些行为属于学术作弊？大学生应如何树立正确的考试诚信意识？
9.  本科生在申请保研、评奖评优时，对学术成果（如论文、竞赛奖项）的申报有哪些诚信要求？
10. 大学生在参与导师的科研项目时，如何遵守实验室规章制度和数据管理规范？

## 三、 研究生专属类
11. 研究生在学位论文开题阶段，如何避免“选题重复”或“变相抄袭他人研究思路”的问题？
12. 研究生在实验过程中，出现数据与预期不符的情况时，能否擅自修改、编造实验数据？正确的做法是什么？
13. 博士/硕士学位论文的“查重率合格”是否等同于“没有学术不端”？为什么？
14. 研究生在发表学术论文时，如何处理与导师、同门的署名顺序问题？若对署名有异议，应通过什么途径沟通？
15. 研究生在学术会议上汇报成果时，是否可以隐瞒研究中的不足之处？简述学术交流中的诚信要求。

## 四、 科研人员与大学老师专属类
16. 科研人员在申请科研基金项目时，如何保证申报材料的真实性？夸大研究基础、伪造前期成果会面临哪些后果？
17. 大学老师在指导学生论文时，若发现学生存在抄袭行为，应该承担哪些责任？正确的处理方式是什么？
18. 科研团队在共享实验数据时，如何平衡“数据开放共享”与“知识产权保护”的关系？
19. 大学老师在学术评审（如论文审稿、项目评审、职称评定）过程中，应遵守哪些回避原则和保密要求？
20. 科研人员在发表学术成果后，若发现研究存在重大错误或疏漏，应该采取什么措施进行补救？
